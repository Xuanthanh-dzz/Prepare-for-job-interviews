# Stack ưu tiên cho repo

Repo này tập trung vào **.NET Full Stack** thay vì cố bao phủ mọi ngôn ngữ/framework.

## Core Backend

### 1. C# / .NET
Phần nền tảng ngôn ngữ và runtime.

### 2. ASP.NET Core / Web API
HTTP pipeline, DI, auth, validation, API design, resilience.

### 3. Entity Framework Core
Query, tracking, transaction, concurrency và performance.

### 4. SQL
Query, index, execution plan, transaction, locking và data modeling.

## Core Frontend

### 1. JavaScript
Nền tảng runtime của frontend.

### 2. TypeScript
Type system và tooling dùng trực tiếp trong Angular.

### 3. HTML / CSS / Web Platform
DOM, browser, accessibility, storage, networking và layout.

### 4. Angular
Component, DI, Router, Forms, Signals, RxJS, performance, testing và architecture.

## Nguyên tắc ưu tiên nội dung

1. **Công nghệ gắn trực tiếp với vị trí .NET Full Stack** được làm sâu trước.
2. **Ngôn ngữ nền tảng** được ưu tiên hơn câu hỏi framework học thuộc.
3. Mỗi level tăng theo khả năng làm việc:
   - Intern: fundamentals
   - Junior: build feature
   - Middle: trade-off + performance
   - Senior: architecture + production failure modes
4. Các framework khác chỉ thêm khi có giá trị mở rộng thị trường rõ ràng; không làm loãng core track.

## Track hiện tại

**Backend:** C# → .NET → ASP.NET Core → EF Core → SQL

**Frontend:** JavaScript → TypeScript → HTML/CSS/Web Platform → Angular

**Full Stack:** HTTP/API → Security → Testing → Docker/CI-CD → Azure/Cloud → Architecture

## Market expansion sau core track

Sau khi các module C#/.NET, ASP.NET Core, EF Core, SQL và Angular đã đủ sâu, repo mới mở rộng các kỹ năng giúp tăng phạm vi vị trí ứng tuyển:

- React — mở rộng lựa chọn Frontend/Full Stack
- Docker / CI-CD
- Azure / cloud fundamentals
- Redis / caching
- Messaging
- Observability
- System Design

Nguyên tắc là **không làm rộng trước khi core track đủ sâu để đi phỏng vấn thực tế**.
